# V1.2 Cost Governor

`CostGovernor` gates provider calls before execution. Local aliases
(`hufi-qwen9-fast`, `hufi-qwen9`, `hufi-gemma`, and local adapters) always
account for 0 EUR while still allowing token and latency telemetry to be
recorded by callers. External calls require an explicit positive budget and
are rejected when the reserved amount would exceed the configured limit.
