# HufiAgents V1.1.0

## Release scope

- Dynamic agents, persistent messaging, delegation and fan-out/fan-in.
- Routines, controlled workspaces/sessions and connector registry.
- Chat-first UI with real agent and routine creation, approval cards and `/legacy`.
- Read-only HufManager team mission through the existing local Qwen router,
  independent reviewer and audit trail.
- Release gates: routine intent confirmation, refusal-aware review and
  reachable tool-call approvals.
