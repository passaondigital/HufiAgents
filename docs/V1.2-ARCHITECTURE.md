# HufiAgents V1.2 Architecture

V1.2 extends the SQLite-first persistence layer with typed work evidence, a company graph, rooms, reusable skills, scoped memory, progressive context, learning gates, cost governance and credential handles. All additions are additive migrations; existing missions, tasks, agents, approvals and audit events remain intact.

Security boundaries are explicit: evidence is sanitized before persistence, memory and skills never contain credentials, and connectors receive opaque credential handles.
