# V1.2 Org Graph

The organization model is a typed graph, not an org-chart tree. Teams,
projects, resources, and chat rooms are persistent nodes. Relationships are
soft-removable edges (`reports_to`, `member_of_team`, `works_on_project`,
`responsible_for_resource`, and `may_use_resource`). Membership never grants
credentials or expands an agent's risk ceiling. Archived agents and teams
cannot gain new memberships; reporting edges reject self-links and cycles.

Credential records are metadata-only handles. Secret values belong in an
external secure connector and are never returned by this API.
