# HufiAgents V1.1.1

Release date: 2026-09-08

V1.1.1 refines the V1.1 product experience without changing the underlying
workforce, approval, audit, or local-model security model.

## Product polish

- The normal product name for `Hufi Chief` is now **Hufi**. Technical roles
  remain available under Details / System.
- Built-in agents use human-readable labels: Entwicklung, Integration,
  Projektleitung, Qualitätsprüfung, and Sicherheit.
- Routine creation uses a Hufi modal with plain-language choices. Native
  browser prompts are no longer part of the product flow.
- Chat-created routines keep natural-language confirmation and do not expose
  backend schedule syntax.
- Result cards safely render common Markdown constructs. Content is rendered
  as DOM text and safe HTTP(S) links; raw HTML is not executed.
- Technical metadata is behind Details / System, and Computer clearly states
  that persistent desktop/browser control is not yet shipped.

## Branding

- The normal UI now uses the Hufi orange, black/anthracite, white, and warm
  grey palette.
- Primary actions, focus, selection, links, chat bubbles, and active/completed
  states use warm orange or neutral presentation.
- Blue, cyan, turquoise, and green accents were removed from the normal UI.
- Agent avatars and the new-agent color picker use a fixed warm palette.

## Validation

- Browser product gate passed at 7/7 desktop, tablet, and mobile breakpoints.
- The browser gate recorded zero console errors, zero network errors, no
  horizontal overflow, and passed keyboard, touch, routine modal, Markdown
  security, and 10-year-old UX checks.
- PR #18 CI passed before merge. Production smoke confirmed service health,
  HTTPS health, local-router availability, persisted missions, and audit data.

## Known limit

Computer and browser sessions are foundation/preparation only. A persistent
desktop/browser is not included in this release.
